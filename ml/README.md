# Learned pond-site suitability

Training and evaluation code for the model that ranks pond sites in Chhattisgarh.
The deployed model is `backend/app/models/site_model.json`; the server evaluates it with
NumPy (`backend/app/services/site_model.py`).

## Reproduce

```bash
pip install -r ml/requirements.txt
cd ml
python fetch_osm_ponds.py                 # OpenStreetMap water bodies -> data/osm/
python build_dataset.py chhattisgarh      # terrain pipeline on 134 tiles -> data/samples_chhattisgarh.csv
python train_site_model.py chhattisgarh   # evaluate + export the model
python build_dataset.py india             # optional: the all-India study
python train_site_model.py india
```

`data/osm/` and `data/samples_*.csv` are committed; elevation tiles and per-tile grids
(`data/elevation_cache/`, `data/tiles_*/`) are regenerated by `build_dataset.py`.

## Data

* **Positives:** OpenStreetMap water polygons (`natural=water`, `landuse=reservoir|basin`)
  of 0.1-20 ha, excluding rivers, canals and streams. One sample per pond, at the cell
  under the pond.
* **Negatives:** 3 per pond, random cells in the same tiles at least 250 m from any mapped
  water body.
* **Tiles:** about 4.4 x 4.4 km, chosen at random among those with at least 3 mapped ponds,
  up to 15 per district, run through the same elevation download, sink filling, D8 and
  flow accumulation as the app.

Unmapped ponds make some negatives wrong, and the smallest ponds are below the 30 m
resolution of the elevation data; both push all scores towards 0.5.

## Features (`backend/app/services/site_features.py`)

All describe the land around a cell at fixed distances in metres:

| Feature | Meaning |
|---|---|
| `tpi_150m`, `tpi_500m` | elevation minus the local mean: valley floor (negative) vs ridge (positive) |
| `slope_ring_60_200m`, `slope_ring_200_500m` | mean slope in a ring around the cell |
| `relief_250m`, `relief_500m` | highest point nearby, above the cell |
| `ruggedness_500m` | elevation range within 500 m |
| `log_upstream_area`, `log_upstream_area_100m` | contributing area at / near the cell |
| `wetness_index` | ln(upstream area / tan(surrounding slope)) |

The cell's own slope and fill depth are left out on purpose: an existing pond flattens
the elevation model under it, and the model would learn to spot flat water instead of
good terrain.

## Evaluation protocol

The districts were fixed in `regions.py` before any Chhattisgarh results were seen:

* **Training (6):** Raipur, Bemetara, Durg, Dhamtari, Baloda Bazar, Kawardha. Used for
  leave-one-district-out cross-validation and to fit the final model.
* **Held-out test (3):** Mahasamund, Janjgir-Champa, Rajnandgaon. No overlap with the
  training districts (checked), scored once with the final model.

The hand-weighted formula the app used before is scored on exactly the same samples.
"Top-10 hit rate" runs the app's own selection (best 10 sites, at least 10 cells apart)
on every tile and counts picks within 100 m of a mapped pond.

## Results (`results_chhattisgarh.json`)

| | Model | Formula | Random |
|---|---|---|---|
| Cross-validation ROC-AUC (6 districts, 664 ponds) | 0.702 | 0.501 | 0.50 |
| **Held-out ROC-AUC (3 districts, 399 ponds)** | **0.697** | 0.505 | 0.50 |
| Held-out precision-recall AUC | 0.477 | 0.260 | 0.25 |
| Held-out top-10 hit rate (450 picks) | 9.3% | 6.4% | 4.5% |

Per held-out district (ROC-AUC, model vs formula): Mahasamund 0.65 vs 0.51,
Janjgir-Champa 0.72 vs 0.50, Rajnandgaon 0.70 vs 0.52.

Most useful features (permutation importance): `tpi_500m`, `slope_ring_200_500m`,
`relief_250m`, `tpi_150m`.

## Why the model is limited to Chhattisgarh (`results_india.json`)

The first attempt trained one model on 8 regions across India (483 ponds) and evaluated it
leave-one-region-out. It reached ROC-AUC 0.52 (formula 0.50): essentially no transfer. The
same feature points in opposite directions in different landscapes, for example
`tpi_500m` (valley vs ridge) separates ponds at 0.63 in Bankura but 0.27-0.28 in Jalna and
Kolar, where tanks sit in valley cascades. Ranking features within each area
(`experiment_normalisation.py`) did not help (0.51). Ponds in Bankura, small and dug next
to villages, show no terrain signal at all.

The app therefore uses the model only inside Chhattisgarh's bounding box and the formula
elsewhere.
